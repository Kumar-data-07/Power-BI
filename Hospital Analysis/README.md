# 🏥 Healthcare Operations & Billing Analytics

An end-to-end data analytics project using **MySQL and Power BI** to analyze healthcare admissions, hospital performance, billing, medical conditions, insurance providers, patient demographics, and length of stay.

---

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, starting with raw healthcare data and transforming it into an interactive Power BI dashboard.

The data was first processed and cleaned using **MySQL**, where duplicate records were identified, dates were transformed, and analytical fields were created.

The cleaned dataset was then connected to **Power BI** to build a two-page interactive dashboard for hospital operations and billing analysis.
