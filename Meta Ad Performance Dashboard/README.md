# 📊 Meta Ad Performance Dashboard – Power BI

## 📌 Project Overview

The **Meta Ad Performance Dashboard** is an interactive Power BI dashboard designed to analyze and monitor the performance of Meta (Facebook/Instagram) advertising campaigns.

The dashboard transforms raw advertising data into meaningful insights, helping users understand **ad spend, impressions, clicks, conversions, revenue, and campaign performance**. It provides an easy-to-use visual interface for evaluating marketing effectiveness and identifying opportunities for optimization.

## 🎯 Project Objectives

* Analyze overall Meta advertising performance.
* Track key marketing and campaign KPIs.
* Compare campaign performance across different dimensions.
* Identify high-performing and underperforming campaigns.
* Understand the relationship between advertising spend and results.
* Provide actionable insights for improving campaign efficiency.

## 🛠️ Tools & Technologies

* **Power BI** – Data visualization and dashboard development
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and KPIs
* **Excel/CSV** – Data source
* **GitHub** – Project documentation and portfolio

## 📈 Key KPIs

The dashboard includes important advertising performance metrics such as:

* 💰 **Total Ad Spend**
* 👁️ **Impressions**
* 🖱️ **Clicks**
* 🎯 **Conversions**
* 💵 **Revenue**
* 📊 **CTR (Click-Through Rate)**
* 💲 **CPC (Cost Per Click)**
* 📈 **ROAS (Return on Ad Spend)**
* 🔄 **Conversion Rate**

## 📊 Dashboard Features

### 1. Performance Overview

Provides a high-level summary of the overall advertising performance using KPI cards and visualizations.

### 2. Campaign Analysis

Allows users to compare campaigns and identify which campaigns generate the best results.

### 3. Advertising Spend Analysis

Analyzes how the advertising budget is distributed and compares spending against campaign outcomes.

### 4. Engagement Analysis

Tracks impressions, clicks, CTR, and other engagement-related metrics to understand audience interaction with advertisements.

### 5. Conversion & Revenue Analysis

Examines conversions and revenue generated from advertising campaigns to evaluate campaign effectiveness.

### 6. Interactive Filters

Users can filter and explore the data based on available dimensions such as:

* Campaign
* Ad Set
* Advertisement
* Date
* Audience/Demographic
* Platform or Placement

## 🔄 Data Preparation

The dataset was processed using **Power Query** before creating the dashboard.

The data preparation process included:

1. Importing the raw advertising dataset.
2. Removing unnecessary columns.
3. Handling missing or inconsistent values.
4. Correcting data types.
5. Creating calculated columns where required.
6. Structuring the dataset for analysis.
7. Loading the cleaned data into Power BI.

## 🧮 DAX & Calculations

DAX measures were created to calculate important performance indicators such as:

* Total Spend
* Total Impressions
* Total Clicks
* Total Conversions
* Total Revenue
* CTR
* CPC
* Conversion Rate
* ROAS

These measures allow the dashboard to dynamically respond to user selections and filters.
