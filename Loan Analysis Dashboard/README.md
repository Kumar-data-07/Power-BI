# 💰 Loan Analysis Dashboard – Power BI

## 📊 Project Overview

The **Loan Analysis Dashboard** is an interactive Power BI project designed to analyze loan applications, borrower characteristics, loan performance, and default patterns.

The dashboard transforms raw loan data into meaningful visual insights that can help financial institutions understand **loan demand, borrower profiles, repayment behavior, and default risk**.

## 🎯 Objectives

* Analyze overall loan application performance
* Identify patterns in loan defaults
* Understand borrower demographics and financial characteristics
* Compare approved and rejected loan applications
* Analyze loan amounts and repayment behavior
* Identify factors associated with higher default risk
* Provide an interactive dashboard for data-driven decision-making

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculated columns
* **CSV** – Source dataset
* **Data Analysis** – Loan performance and risk analysis

## 📁 Dataset

The project uses a loan dataset containing information about borrowers and their loan applications.

Key attributes include:

* Loan amount
* Income
* Credit history
* Employment information
* Education
* Loan term
* Property/location information
* Loan status
* Default-related information

## 📌 Dashboard Features

### 1. Loan Overview

Provides a high-level summary of the loan portfolio, including:

* Total loan applications
* Total loan amount
* Approved loans
* Rejected loans
* Default rate
* Average loan amount

### 2. Loan Performance Analysis

Analyzes loan outcomes using:

* Approved vs. rejected applications
* Default vs. non-default loans
* Loan amount distribution
* Loan performance by category
* Monthly/yearly trends

### 3. Borrower Analysis

Examines borrower characteristics such as:

* Income levels
* Employment status
* Education
* Credit history
* Demographics
* Property/location information

### 4. Risk Analysis

Identifies patterns that may contribute to loan default, including:

* Credit history
* Income level
* Loan amount
* Employment status
* Loan-to-income relationship
* Other borrower characteristics

## 📈 Key KPIs

The dashboard focuses on important financial KPIs such as:

| KPI                 | Description                           |
| ------------------- | ------------------------------------- |
| Total Applications  | Total number of loan applications     |
| Total Loan Amount   | Total value of loans requested/issued |
| Approval Rate       | Percentage of applications approved   |
| Rejection Rate      | Percentage of applications rejected   |
| Default Rate        | Percentage of loans that defaulted    |
| Average Loan Amount | Average loan amount                   |
| Average Income      | Average borrower income               |
