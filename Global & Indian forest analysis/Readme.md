# 🌳 India Forest Analysis — 1990–2023

## 📊 Project Overview

This project analyzes India's forest area and forest coverage from **1990 to 2023** using World Bank forest data.

The project uses **Python for data preparation, MySQL for ETL and SQL analysis, and Power BI for interactive visualization**.

The objective is to understand India's long-term forest trends, forest coverage changes, yearly growth, and decade-wise performance.

---

## 🎯 Objectives

- Analyze India's forest area from 1990–2023
- Track changes in forest coverage percentage
- Calculate overall forest area growth
- Analyze year-over-year forest growth
- Compare forest area across decades
- Compare average forest coverage across decades
- Build an interactive Power BI dashboard

---

## 🛠️ Tools & Technologies

- **Python** – Data cleaning and preprocessing
- **Pandas** – Data transformation and analysis
- **MySQL** – Data storage, ETL and SQL analysis
- **Power BI** – Dashboard and data visualization
- **World Bank Data** – Data source
